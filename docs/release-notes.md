### ダウンロード

- **Apple Silicon (M1以降)**: `macos-arm64.zip`
- **Intel Mac**: `macos-x86_64.zip`
- macOS 13以降。ZIPを解凍し、Paratool.appをアプリケーションフォルダへ移動してください。

### 初回起動

このビルドはローカル署名のみで、AppleのDeveloper ID署名・公証は行っていません。初回起動でブロックされた場合は、ダウンロード元を確認したうえで「システム設定 → プライバシーとセキュリティ → このまま開く」から許可してください。

保存先フォルダへのアクセスを許可してください。画像が出ない場合は、メニューバーのParatoolから「スクショの保存先を選択…」を選んでください。

macOS標準の右下プレビューは `⌘⇧5 → オプション → フローティングサムネールを表示` をオフにすると非表示になります。標準プレビューが有効だと、ファイル保存まで取り込みが遅れます。

履歴はアプリ終了でリセットされます。Ctrl付き撮影に加え、他アプリでコピーしたPNG/TIFF画像も取り込みます。Paratool自身のコピーは再取り込みしません。文字はEnterで確定、Shift+Enterで改行、Escで取消できます。
